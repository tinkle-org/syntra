# Maintainers

Active roster, effective 2026-10-29. This file is published alongside
[`GOVERNANCE.md`](GOVERNANCE.md) and is the roster referenced by its approval
rules.

| Public account | Role | Scope |
|---|---|---|
| [oscarlaw](https://github.com/oscarlaw) | Active maintainer; repository owner | Normative acceptance including governance amendments, specification freeze, release authorization |

The owner authority for the 2026-10-29 bootstrap transition was verified from
the GitHub repository administration record for `tinkle-org/syntra`
(`permissions.admin = true` for `oscarlaw`). The decision is recorded in
[`docs/decisions/0001-bootstrap-ratification.md`](docs/decisions/0001-bootstrap-ratification.md).

Roster changes follow the rule in force before the change. Removing or
deactivating a maintainer to alter the quorum for an open decision is not a
valid substitute for resolving an objection. With no active maintainer,
normative acceptance and release authorization are blocked.
